# What's new in .NET 11

Tiny demos for short videos about .NET 11 and C# 15. Each folder is one feature, one project, and one README.

Requires the [.NET 11 SDK](https://dotnet.microsoft.com/download/dotnet/11.0) (`global.json` pins 11.0.100).

| # | Feature | Status | Video |
| --- | --- | --- | --- |
| 01 | [C# unions](01-unions/) | GA (C# 15) | _coming soon_ |
| 02 | [Closed classes](02-closed-classes/) | GA (C# 15) | _coming soon_ |
| 03 | [WinForms visual styles](03-winforms-visual-styles/) | Opt-in (Windows only) | _coming soon_ |
| 04 | [Runtime async](04-runtime-async/) | **Preview**, opt-in | _coming soon_ |
| 05 | [C# expressions in MAUI XAML](05-maui-xaml-csharp-expressions/) | **Preview** | _coming soon_ |

C# 15 is the default language version for `net11.0`, so no project sets `LangVersion`.
